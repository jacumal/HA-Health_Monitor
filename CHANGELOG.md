# Changelog

## 0.1.0 - Initial installable foundation

- Add Home Assistant custom integration package and manifest.
- Add graphical config flow and options flow.
- Add availability scan for unavailable entities.
- Add opt-in freshness checks for explicitly selected entities.
- Add monitoring sensors, problem binary sensor and manual scan service.
- Add local diagnostics and English/Spanish translations.

This is an early development build. Integration monitoring, automation diagnostics, incident lifecycle/persistence, health score and Lovelace frontend are not included yet.
